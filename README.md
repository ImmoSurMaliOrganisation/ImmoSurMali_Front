# 🏠 ImmoStarterPro Angular Pro Kit v1.0

Professional Real Estate Template built with **Angular 21** & **Tailwind CSS 4**.

## 🚀 Features
- **Modern Tech Stack**: Angular 21 (Standalone, Signals, No Zone.js).
- **Responsive & Bento Design**: Optimized for Mobile & Desktop.
- **Dark Mode**: Fully integrated with Tailwind 4.
- **Interactive Maps**: Built-in Leaflet integration (Open Source).
- **SEO Ready**: Clean structure for better indexing.

## 📦 Installation
1. Extract the ZIP file.
2. Run `npm install`.
3. Start the project with `npm start`.

## 🛠 Customization
Change colors and branding in `tailwind.config.js` and `app.config.ts`.
